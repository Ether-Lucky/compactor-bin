Bench Test Guide

Test every part you already have, one at a time, before anything goes into the bin. A part that passes here is one less thing to suspect when the full machine doesn't work. The breadboard page comes first; the last pages show how to connect the whole machine once everything passes.

Bring to the table

  • Laptop with Arduino IDE 2 installed
  • Arduino USB cable, breadboard, jumper wires
  • The sketch bench_test.ino (full code at the back of this guide)
  • Phone charger, 5V 2A or more, and an old USB cable you can cut (or a power bank)
  • Ruler or tape measure, an empty 500 mL bottle
  • 220 Ω resistors ×3 (for the LEDs)
  • Multimeter, if anyone has one
  • Optional: 12V adapter 2A or more, for the actuator tests

Rules for today

  • No 220V wiring. The power supplies aren't here yet.
  • Unplug the USB cable before changing any wire.
  • Never connect an actuator or the servo's power to an Arduino pin.
  • Keep fingers away from a moving actuator rod.
  • A 12V car or motorcycle battery can melt wires. Only use one with a 10A fuse in the line.

How each test works

Upload bench_test.ino once. Open the Serial Monitor at 9600 baud, type the number for a part and press Enter. Wire only the part you're testing, check the result against Pass if, then tick the box and write the reading on the results sheet at the back.

Breadboard basics

It lets several parts share the Arduino's 5V and GND without soldering. Most "it doesn't work" problems are a wire one hole off.

How the holes connect

  1. A column of 5 holes (a to e) is one connection. Two legs in the same column are joined.
  2. The other half (f to j) is a separate column. The gap in the middle splits them, so a part can sit across it.
  3. A whole rail along the edge is one connection. Use the red + rail for 5V and the blue − rail for GND.

Never on the breadboard: 12V, the actuators, the BTS7960's B+ B− M+ M− wires, or the servo's power. The servo pulls over 2A; a breadboard contact handles about 1A.

Bench layout: every 5V part on one board

Build this once and tests B, D, E, F and G all run without rewiring. Unplug USB while you build it.

Power rails

Arduino 5V to the top + rail, GND to the top − rail. One long black jumper joins the top − rail to the bottom one (right edge).

Sensors

Pins in row j: VCC, TRIG, ECHO, GND. Short jumpers take VCC to + and GND to −. TRIG and ECHO go to the Arduino in the same column.

LEDs and buzzer

Each LED: Arduino pin, then a 220 Ω resistor across the gap, then the long leg. The short leg goes straight into the − rail. Buzzer: + leg to D12's column, − leg into the − rail.

Button and E-stop are panel parts: one wire to the pin, one to any − rail hole. In the finished bin, move to screw terminals or a soldered board, because the press shakes jumpers loose.

AArduino UNO

NowAbout 10 min

Proves the board, the USB cable and the laptop can talk. Every other test depends on this one.

  1. Plug the Arduino into the laptop. The ON light on the board should light up.
  2. In Arduino IDE: Tools › Board › Arduino Uno, then Tools › Port and pick the new COM port.
  3. Open bench_test.ino and click Upload (the right arrow).
  4. Open Tools › Serial Monitor and set it to 9600 baud.

Pass if

"Upload done" appears, and the Serial Monitor shows the menu starting with === Compactor bin bench test ===.

If it fails

  • No COM port: cheap UNO boards use the CH340 chip. Install the CH340 driver, then replug.
  • Upload error: check the Board and Port, try another USB cable (some only charge).
  • Garbled text: the Serial Monitor isn't at 9600 baud.
Notes

BHC-SR04 sensors (slot and fill)

NowAbout 15 min

Proves each sensor measures distance correctly, including off a curved plastic bottle. Test both sensors on the slot pins first, then wire the fill sensor to its own pins.

  1. Wire the sensor as shown. Unplug USB while wiring.
  2. Type 1. Hold a flat book 10 cm, then 30 cm, then 60 cm in front of the sensor. Write the readings down.
  3. Hold the empty bottle sideways 10 cm away. Watch for a minute.
  4. Swap in the second sensor and repeat.
  5. Move the fill sensor to D4 TRIG, D7 ECHO and type 2 to check those pins.

Pass if

Readings are within ±2 cm of the ruler. The bottle reads about 10 cm most of the time (an odd jump is normal on curved plastic).

If it fails

  • "no echo" every time: TRIG and ECHO are swapped, or VCC isn't on 5V.
  • Always 0 or random: loose jumper. Push the wires in firmly.
  • Below 2 cm the sensor can't measure. That's normal.
Notes

CMG996R servo (lid)

NowAbout 15 min

Proves the servo turns smoothly to 90° and back. It runs from a phone charger because it can pull over 2A, which would reset the Arduino.

  1. Cut the old USB cable and strip the ends. Red = +5V, black = ground. Ignore the white and green wires.
  2. Wire as shown. The charger's ground must also go to an Arduino GND.
  3. Plug in the charger, then type 3. The servo swings 0° → 90° → 0° three times.
  4. Fit a servo horn and check it holds still afterwards.

Pass if

It moves smoothly both ways, stops without buzzing, and the Serial Monitor prints "Done" without the menu restarting on its own.

If it fails

  • Menu restarts mid-test: the servo is drawing power through the Arduino. Use the charger.
  • Jitters or stalls: the charger is too weak. Use one rated 2A or more.
  • Doesn't move at all: signal wire not on D9, or grounds not joined.
Notes

DPush button

NowAbout 5 min

Proves the press-now button contacts work. The LA38 has two contact pairs: NO (normally open) and NC (normally closed). The button uses the NO pair.

  1. Find the pair marked NO (often numbered 3 and 4). With a multimeter on beep mode, NO beeps only while pressed.
  2. Wire one NO terminal to A3, the other to GND.
  3. Type 4, then press and release a few times.

Pass if

Each press prints PRESSED and each release prints released, with no extra flicker.

If it fails

  • Reversed (PRESSED while not touched): you used the NC pair. Move to NO.
  • Nothing changes: loose screw on the contact block.
Notes

EEmergency stop

NowAbout 5 min

Proves the E-stop really opens its contact when pressed. In the bin it sits in the 12V line, so it must use the NC pair: closed normally, open when slapped.

  1. Find the NC pair (often numbered 1 and 2). With a multimeter on beep mode, NC beeps while released and goes silent when pressed.
  2. Wire one NC terminal to A4, the other to GND. (A4 is only for this test.)
  3. Type 5. Press the mushroom, then twist it to release.

Pass if

Pressing prints PRESSED (contact open, stop) and it stays pressed until you twist it. Releasing prints released (contact closed, normal).

If it fails

  • Reversed messages: you're on the NO pair. Move to NC.
  • Pops back up by itself: it's a momentary button, not a latching E-stop.
Notes

FBuzzer

NowAbout 3 min

Proves the active buzzer beeps from a plain on/off signal.

  1. The longer leg (or the side marked +) goes to D12, the other to GND.
  2. Type 6.

Pass if

Three clear beeps.

If it fails

  • Silent: legs reversed. Swap them.
  • Only a faint click: it's a passive buzzer, which needs a tone signal. Tell the group lead.
Notes

GStatus LEDs

NowAbout 10 min

Proves the green, yellow and red LEDs light from their pins. Each LED needs its own 220 Ω resistor, or it burns out.

  1. For each LED: pin → 220 Ω resistor → long leg. Short leg → GND. Green on A0, yellow on A1, red on A2.
  2. Type 7.

Pass if

Green, yellow, red light one after another, three rounds.

If it fails

  • One LED stays dark: it's backwards. Turn it around.
  • Without 220 Ω resistors, skip this test and come back to it later.
Notes

HLinear actuators, direct

Needs 12VAbout 15 min

Proves each actuator moves both ways and stops by itself at each end, using 12V straight to the actuator without the Arduino.

  1. Lay the actuator flat with the rod free. Use a 12V adapter rated 2A or more.
  2. Touch red to +12V and black to −. The rod should extend. Time how long the full stroke takes.
  3. Swap the two wires. The rod should pull back in.
  4. Repeat for the second actuator.

Pass if

It extends and retracts, and stops by itself at both ends (its built-in limit switches). A full 200 mm stroke takes about 29 s.

If it fails

  • Hums but doesn't move: the adapter is too weak.
  • Moves one way only: the limit switch at that end may be stuck. Note which actuator.
Stroke time

IBTS7960 driver with an actuator

Needs 12VAbout 15 min

Proves the Arduino can drive an actuator out and back through the driver. This is the exact wiring the bin uses, minus the fuse and E-stop.

  1. Logic side: VCC → 5V, GND → GND, RPWM → D5, LPWM → D6, R_EN and L_EN together → D8.
  2. Power side: 12V adapter + → B+, − → B−. Actuator red and black → M+ and M−.
  3. Type 8, check the rod is clear, then type y.

Pass if

The rod moves out for 3 s (about 2 cm), pauses, then comes back.

If it fails

  • Moves in first, then out: swap the actuator wires on M+ and M−.
  • Doesn't move: R_EN and L_EN not on D8, or the 12V isn't on B+ and B−.
  • Driver gets hot: stop and check the M+ / M− wires aren't touching.
Notes

JBuck converter, terminal block, jumpers

Buck needs 12VAbout 10 min

Quick checks for the remaining parts.

  1. Buck converter: 12V adapter to its input (+ to +). Measure the USB output with a multimeter, or plug in a phone.
  2. Terminal block: clamp a stripped wire in every screw and tug it. Look for cracks.
  3. Jumper wires: tug each end. With a multimeter, check a few for continuity. Throw away any loose one.

Pass if

Buck output reads 5.0-5.3 V (or the phone shows charging). Every terminal grips and every jumper holds.

If it fails

  • Buck reads 0 V: input polarity reversed. Unplug immediately and swap.
Notes

After the tests: connect the whole machine

Build it up in stages and test after each one, so a problem shows up right where you added it. The machine presses bottles in bundles: bottles pile up in the bin, and the plate only comes down when the fill sensor sees the pile at the crush line for a full second. A bottle falling past the sensor is too quick to count.

+12V+5VGroundSignal (thick: a bundle of wires)Motor (polarity flips to reverse)220V, adults only
  1. Fuse right after the 12V supply. 15A for two actuators (they draw about 12A when they stall at the end of a press). Use 10A if you only fit one.
  2. E-stop in the 12V line, NC pair. Slapping it cuts the actuators instantly. The Arduino keeps running.
  3. Buck converter takes 12V before the E-stop, so the Arduino stays on when the E-stop is pressed.
  1. Both actuators on the same M+ and M−, red to M+, black to M−. If one rod moves the opposite way, swap only its two wires.
  2. One ground for everything: 12V −V, 5V −V, BTS7960 B− and GND, Arduino GND, servo brown, buck IN−. A missing ground is the most common fault.

Before switching on

  • With a multimeter on beep mode: no beep between +12V and ground
  • Fuse fitted, E-stop released (pops up)
  • All six minus wires on the ground bus, screws tight
  • No bare copper sticking out of any terminal
  • Plate bolted to both rods, nothing inside the bin, hands out

Build order

  1. Breadboard parts

    Wire the bench layout. Run tests 1, 2, 4, 6, 7 again.

  2. Mount the sensors in the bin

    Slot sensor in the top of the slot tube, looking down across the opening. Fill sensor under the housing floor at the back corner, looking straight down; cut a notch in the plate so it can see past it. Use 4-core cable, under 1 m, for the long runs.

  3. Front panel

    LEDs (with 220 Ω), buzzer and push button on the housing front. The E-stop goes there too, but it is wired in stage 5.

  4. 5V supply and servo

    An adult connects the 220V side. Then: 5V +V to the servo red, −V to the ground bus, signal to D9. Run test 3.

  5. 12V chain

    Supply +V, fuse, E-stop (NC), BTS7960 B+. B− to the ground bus. Both actuators on M+ / M−. Buck converter from the fuse output to the Arduino USB.

  6. Driver logic

    D5 RPWM, D6 LPWM, D8 to R_EN + L_EN, 5V and GND, as in test I. Run test 8: both rods move together, the same way.

  7. Upload the real program

    Upload compactor_bin.ino (the bundle-press version) and do the first power-up checks below.

First power-up: what you should see

  1. Yellow LED. The plate goes up for 31 s (the limit switch stops it if it is already up). One beep, then green.
  2. Hold a bottle in the slot: the lid opens, then closes after you let go, and the plate stays up.
  3. Press the E-stop for this step, so the plate can't move. Hold a flat box 10 cm under the fill sensor: two beeps, yellow light. Keep holding it for about a minute, until the press and return timers end: red light, three beeps, lid locked. Take the box away: green again.
  4. Release the E-stop. Drop real bottles in until the pile reaches the crush line: the plate presses the whole pile, then goes back up.

Parts that failed, and what we'll do

The test sketch: bench_test.ino

Also in the project folder at arduino/bench_test/bench_test.ino. Copy it into a new sketch in Arduino IDE if you don't have the file.

/*
  Bench test for the compactor bin parts, one part at a time.

  1. Upload this sketch.
  2. Open Tools > Serial Monitor, set 9600 baud.
  3. Type a number and press Enter:

     1  Slot sensor   (HC-SR04 on D2 TRIG, D3 ECHO)   prints distance for 15 s
     2  Fill sensor   (HC-SR04 on D4 TRIG, D7 ECHO)   prints distance for 15 s
     3  Servo         (signal D9, power from a separate 5V supply)  0 -> 90 -> 0, three times
     4  Push button   (A3 to GND)                      shows presses for 15 s
     5  E-stop        (A4 through the NC contact to GND) shows pressed / released for 15 s
     6  Buzzer        (D12)                            three beeps
     7  LEDs          (A0 green, A1 yellow, A2 red, each through 220 ohm)  cycles 3 times
     8  Actuator      (BTS7960: D5 RPWM, D6 LPWM, D8 enable; needs 12V on B+ / B-)
                      asks before moving: 3 s out, pause, 3 s back

  Pins match compactor_bin.ino, except A4, which is only used here for the E-stop test.
*/

#include <Servo.h>

const int SLOT_TRIG = 2, SLOT_ECHO = 3;
const int FILL_TRIG = 4, FILL_ECHO = 7;
const int ACT_RPWM = 5, ACT_LPWM = 6, ACT_EN = 8;
const int SERVO_PIN = 9;
const int BUZZER = 12;
const int LED_GREEN = A0, LED_YELLOW = A1, LED_RED = A2;
const int BUTTON = A3;
const int ESTOP = A4;

Servo lid;

long readCm(int trig, int echo) {
  digitalWrite(trig, LOW);  delayMicroseconds(2);
  digitalWrite(trig, HIGH); delayMicroseconds(10);
  digitalWrite(trig, LOW);
  long us = pulseIn(echo, HIGH, 25000);
  if (us == 0) return -1;            // no echo
  return us / 58;
}

// true when a real key (not a line ending) is waiting
bool keyWaiting() {
  while (Serial.available()) {
    int c = Serial.peek();
    if (c == '\n' || c == '\r') { Serial.read(); continue; }
    return true;
  }
  return false;
}
void clearInput() { while (Serial.available()) Serial.read(); }

void menu() {
  Serial.println();
  Serial.println(F("=== Compactor bin bench test ==="));
  Serial.println(F("1 Slot sensor   2 Fill sensor   3 Servo   4 Button"));
  Serial.println(F("5 E-stop        6 Buzzer        7 LEDs    8 Actuator"));
  Serial.println(F("Type a number and press Enter. Type any key to stop a running test."));
}

void sensorTest(const char *name, int trig, int echo) {
  Serial.print(F("-- ")); Serial.print(name); Serial.println(F(": distance every 0.25 s for 15 s"));
  unsigned long t0 = millis();
  while (millis() - t0 < 15000 && !keyWaiting()) {
    long cm = readCm(trig, echo);
    if (cm < 0) Serial.println(F("no echo (check wiring, or nothing within 4 m)"));
    else { Serial.print(cm); Serial.println(F(" cm")); }
    delay(250);
  }
}

void servoTest() {
  Serial.println(F("-- Servo: 0 -> 90 -> 0, three times"));
  lid.attach(SERVO_PIN);
  for (int i = 0; i < 3; i++) {
    lid.write(0);  delay(800);
    lid.write(90); delay(800);
  }
  lid.write(0); delay(800);
  lid.detach();
  Serial.println(F("Done. If the Arduino restarted during this test, the servo is not on its own 5V supply."));
}

void inputTest(const char *name, int pin, const char *lowMeans, const char *highMeans) {
  pinMode(pin, INPUT_PULLUP);
  Serial.print(F("-- ")); Serial.print(name); Serial.println(F(": press and release it. Showing changes for 15 s"));
  int last = -1;
  unsigned long t0 = millis();
  while (millis() - t0 < 15000 && !keyWaiting()) {
    int v = digitalRead(pin);
    if (v != last) { Serial.println(v == LOW ? lowMeans : highMeans); last = v; }
    delay(20);
  }
}

void buzzerTest() {
  Serial.println(F("-- Buzzer: three beeps"));
  for (int i = 0; i < 3; i++) { digitalWrite(BUZZER, HIGH); delay(150); digitalWrite(BUZZER, LOW); delay(250); }
}

void ledTest() {
  Serial.println(F("-- LEDs: green, yellow, red, three times"));
  int pins[3] = { LED_GREEN, LED_YELLOW, LED_RED };
  for (int r = 0; r < 3; r++)
    for (int i = 0; i < 3; i++) { digitalWrite(pins[i], HIGH); delay(400); digitalWrite(pins[i], LOW); }
}

void actuatorStop() { analogWrite(ACT_RPWM, 0); analogWrite(ACT_LPWM, 0); }

void actuatorTest() {
  Serial.println(F("-- Actuator through the BTS7960"));
  Serial.println(F("Check: 12V on B+ / B-, actuator on M+ / M-, rod free to move, hands clear."));
  Serial.println(F("Type y and Enter to start, anything else to cancel."));
  clearInput();
  while (!keyWaiting()) {}
  char c = Serial.read(); clearInput();
  if (c != 'y' && c != 'Y') { Serial.println(F("Cancelled.")); return; }
  digitalWrite(ACT_EN, HIGH);
  Serial.println(F("Extending 3 s (RPWM)..."));
  analogWrite(ACT_LPWM, 0); analogWrite(ACT_RPWM, 255); delay(3000);
  actuatorStop(); delay(1000);
  Serial.println(F("Retracting 3 s (LPWM)..."));
  analogWrite(ACT_RPWM, 0); analogWrite(ACT_LPWM, 255); delay(3000);
  actuatorStop();
  digitalWrite(ACT_EN, LOW);
  Serial.println(F("Done. The rod should have moved out about 2 cm, then back."));
}

void setup() {
  Serial.begin(9600);
  pinMode(SLOT_TRIG, OUTPUT); pinMode(SLOT_ECHO, INPUT);
  pinMode(FILL_TRIG, OUTPUT); pinMode(FILL_ECHO, INPUT);
  pinMode(ACT_RPWM, OUTPUT); pinMode(ACT_LPWM, OUTPUT); pinMode(ACT_EN, OUTPUT);
  pinMode(BUZZER, OUTPUT);
  pinMode(LED_GREEN, OUTPUT); pinMode(LED_YELLOW, OUTPUT); pinMode(LED_RED, OUTPUT);
  actuatorStop(); digitalWrite(ACT_EN, LOW);
  menu();
}

void loop() {
  if (!keyWaiting()) return;
  char c = Serial.read();
  delay(50); clearInput();
  switch (c) {
    case '1': sensorTest("Slot sensor", SLOT_TRIG, SLOT_ECHO); break;
    case '2': sensorTest("Fill sensor", FILL_TRIG, FILL_ECHO); break;
    case '3': servoTest(); break;
    case '4': inputTest("Push button", BUTTON, "PRESSED", "released"); break;
    case '5': inputTest("E-stop", ESTOP, "released (contact closed, normal)", "PRESSED (contact open, stop)"); break;
    case '6': buzzerTest(); break;
    case '7': ledTest(); break;
    case '8': actuatorTest(); break;
    default: return;
  }
  clearInput();
  menu();
}
